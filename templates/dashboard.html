📈 今日重点关注
这是系统自动过滤出来的当天值得盯的品种，仅展示评级为 A级（强信号） 和 B级（可交易） 的品种。入选条件：
  • A级：ADX≥30 + 资金面≥60 + 多周期共振 + 基差支撑（全维度对齐）
  • B级：ADX≥25 + 资金面≥50，或共振+强趋势等组合条件
  • 评级为 C/D 的品种不会出现在重点关注中
排名综合考虑评级等级、校准胜率、多周期共振等因素，A级始终排在最前。
🔍 品种库
全市场扫描结果，展示所有品种的方向、评级、胜率、趋势强度等信息。包含 C/D 级品种，方便你全局观察哪些板块强、哪些板块弱，以及为什么某些品种暂时不适合交易。

🧮 列表里每一列是什么意思？

方向 — 系统给出的交易方向：⬆ 看多 / ⬇ 看空 / — 观望（D级信号自动降为观望）。
AI判断 — 核心决策列：AI融合技术面+资金面+基差+分歧信号给出的前向走势判断，是列表中最具实战参考价值的列：
↑趋势延续/↑趋势初期 强势看涨
↑回调待涨 趋势向上等待回调入场
→高位震荡/→低位筑底 等待突破
↓趋势转弱/↓即将反转 趋势末端信号
🔴顶背离风险 / 🟢底背离机会 分歧预警
评级 — 信号质量评级（A/B/C/D）：
A 强信号 全维度对齐，预期胜率 50-58%
B 可交易 核心条件满足，预期胜率 35-45%
C 弱信号 仅AI独立判断，不建议跟单
D 不建议 ADX<20 或基差极端矛盾
趋势阶段 — 趋势生命周期（仅在有明确方向时显示）： 🟢初期 🔵成长 🟡成熟 🔴衰竭
趋势强度 — 5格能量条（ADX），格数越多=趋势越明确。
多周期 — 5个圆点 → 15m/30m/1h/日线/周线。红色=多头，绿色=空头，灰色=震荡。
持续概率 — 当前趋势延续的可能性，综合ADX+阶段+共振+RSI计算。
反转条件 — 触发趋势反转的关键价位。做多跌破支撑转空，做空突破阻力转多。
目标位 — 基于支撑阻力的结构目标价。做多看下一阻力，做空看下一支撑。
盈亏比 — 目标位÷止损的比值。1:2以上绿色，1:1.5蓝色，低于1.5黄色。
🟢🔴基差指示 — 品种名前的小圆点：🟢基差支撑方向 | 🔴基差矛盾 | ⚪中性。代表现货与期货的价差是否支持当前交易方向。
趋势 — 5格能量条，基于 ADX 趋势强度。格数越多代表趋势越明确（不是涨得猛，而是方向越确定）。
多周期 — 5个小圆点，从左到右依次是 15分钟 / 30分钟 / 1小时 / 日线 / 周线。红色=多头，绿色=空头，灰色=震荡。颜色越一致，说明大小周期越同向。

🔥 这些标记是什么意思？

🔥 多周期共振 — 5 个时间周期方向完全一致（全红或全绿），是系统认定的强共识信号。
AI+🐢 AI + 海龟共振 — AI 判断的方向与经典海龟交易法则的突破方向一致，双重确认，参考价值更高。
📊 基差支撑 — 现货与期货价差方向与交易方向一致。做多时基差升水（现货强于期货），做空时基差贴水（现货弱于期货），说明基本面支撑交易方向。
⚠️ 基差矛盾 — 现货与期货价差方向与交易方向矛盾。做多但现货极弱，或做空但现货极强，基本面不支撑当前方向，信号会被降级或直接标记为D级（不建议交易）。

📋 详情页怎么看？

点击任意品种名称进入详情页，核心看点：

  • AI 诊断：一句话总结当前该品种的趋势状态和操作建议。
  • 技术指标：MACD、RSI、布林带、KDJ 四大指标的当前状态和信号。
  • 多周期共振：把 15min/30min/1h/1day/1week 五个周期的方向、强度、RSI 全部摊开，一眼看清大小周期是否同向。
  • 压力支撑：系统自动算出的阻力位和支撑位，是你设止损、止盈的重要参考。
  • 资金分析：持仓量变化、资金流向、量价配合度，判断有没有大资金在参与。
  • 海龟交易：20日/55日高低点、当前是否突破、距离突破还差多少点。
  • 基差分析：现货价格、基差、基差率、历史分位数，从基本面验证交易方向的合理性。
  • 投资者适当性：根据波动率和胜率，提示该品种适合新手、进阶还是专业选手。

✅ 正确的实战参考方法

  1. 先看"今日重点关注"：只看 A/B 级品种，这里已经是系统用多维度过滤后的高质量机会。
  2. 优先选 A 级 + 基差支撑：全维度对齐的信号最可靠，基差支撑说明基本面也在配合。
  3. 点进去看详情页：重点看压力支撑位置、海龟突破状态和基差分位数，决定你的入场点和止损点。
  4. 关注持仓监控：系统对 A/B 级品种自动开仓追踪，评级降为 C/D 时自动平仓，帮你守住纪律。
  5. 控制仓位：波动率大的品种，建议手数会自动减少，不要逆势加仓。
  6. 没有机会就等：如果"今日重点关注"是空的，说明市场当前缺乏高质量信号，空仓观望本身就是最好的操作。
风险提示：系统所有信号均基于历史数据和技术模型自动生成，仅供客观参考，不构成投资建议。期货交易风险极高，请独立判断、严格控制风险。

Q: 数据多久更新一次？

系统每日早上8:00-9:00自动更新全品种分析数据，覆盖 50 个主流期货品种。更新内容包括 5 周期技术分析、持仓量分析、AI 评分、海龟信号等。您可以在页面顶部查看"最新更新时间"。

Q: 胜率是怎么算出来的？

系统采用四层概率融合计算最终胜率：① AI 原始概率（基于技术面+资金面+趋势强度）→ ② 历史回测验证 → ③ 实盘信号校准 → ④ ML 模型预测。四层按权重融合后输出"校准胜率"，比单一指标更可靠。同时，系统还通过信号评级（A/B/C/D）对信号质量做分层，A级信号（全维度对齐+基差支撑）的预期胜率最高。

Q: 多周期圆点从左到右代表什么？

5 个圆点从左到右依次是：15分钟 → 30分钟 → 1小时 → 日线 → 周线。红色 = 该周期看多，绿色 = 该周期看空，灰色 = 震荡/观望。5 个颜色完全一致时，名称旁会出现 🔥，表示多周期共振。

Q: 为什么"今日重点关注"有时候是空的？

这不是 bug，而是系统在告诉你：当前市场上没有品种达到 A/B 级标准。重点关注仅展示经过技术面（海龟+ADX）、资金面（量价配合）、多周期共振、基本面（基差验证）多维度筛选后的高质量信号。期货市场不是每天都有好机会，强行出手反而容易亏钱。当重点关注为空时，建议你观望或去"品种库"看看 C/D 级品种为什么不达标，等待下一轮明确信号。

Q: 系统能保证盈利吗？

不能。任何分析工具都无法保证盈利。本系统提供的是基于数据分析的客观参考，帮助您提高决策效率和风险控制能力。期货交易风险极高，请根据自身情况独立判断，严格控制风险。

🎯 信号评级体系（A/B/C/D）

🟢 A级 · 强信号（预期胜率 50-58%）
条件：AI+海龟共振 + ADX≥30 + 资金面≥60 + 多周期共振 + 基差支撑
全维度对齐：技术面、资金面、多周期、基本面（基差）全部指向同一方向。这是系统认定的最高质量信号。
🔵 B级 · 可交易（预期胜率 35-45%）
满足以下任一条件：
  • AI+海龟共振 + ADX≥25
  • 多周期共振 + ADX≥30 + 资金面≥60
  • 海龟确认方向一致 + ADX≥30
  • A级核心条件满足但基差矛盾（降级为B）
🟡 C级 · 弱信号（预期胜率 25-35%）
仅 AI 独立判断，海龟无确认，亦不满足 B 级独立条件。不建议直接跟单，可作为观察参考。
⚫ D级 · 不建议交易
以下情况均标记为 D 级：
  • ADX < 20（趋势不明显，震荡市）
  • 方向为观望
  • AI 与海龟方向矛盾
  • 基差极端矛盾（做多但现货极弱 / 做空但现货极强）

📊 基差/现货验证是什么？

基差 = 现货价格 - 期货价格，是基本面验证技术面的关键维度：

  • 基差升水（现货 > 期货）：现货市场强势，支撑做多观点
  • 基差贴水（现货 < 期货）：现货市场偏弱，支撑做空观点
  • 基差分位 > 60% + 做多：基差支撑，评级可能提升
  • 基差分位 < 40% + 做空：基差支撑，评级可能提升
  • 基差分位 < 15% + 做多：极端矛盾，直接降为D级
  • 基差分位 > 85% + 做空：极端矛盾，直接降为D级
数据来源：AKShare 每日更新的现货价格，系统自动计算基差分位数。

🔄 持仓监控与自动平仓

系统对 A/B 级品种自动开仓追踪，形成完整的信号生命周期：

  • 自动开仓：品种进入重点关注（A/B级）时，系统自动记录开仓信号
  • 自动平仓：以下情况触发自动平仓：
    • 评级降为 C/D 级（不再满足重点关注条件）
    • 方向变为观望
    • 触发止损或止盈条件
    • 基差变为极端矛盾
  • 持仓监控：Dashboard 右侧显示当前 A/B 级品种的模拟持仓和盈亏追踪

⚠️ 什么情况下系统会显示"观望"？

系统对"观望"非常严格，以下情况都会被强制过滤：

  • 与周线/日线大趋势冲突：小周期想逆势操作，直接过滤
  • RSI 极端超买/超卖：追高风险太大，系统禁止追高/追空
  • 疑似假突破：价格突破后快速收回，系统会要求等待确认
  • 波动率极高（ATR > 3.5%）：行情太疯，建议先观望
  • 多周期严重分歧：大小周期互掐，方向不明
  • 基差极端矛盾：做多但现货极弱，或做空但现货极强
  • ADX < 20：市场无明确趋势，震荡为主

  • 持续：AI 预测趋势延续的概率，越高越好
  • 反转条件：触发此条件时趋势可能反转，是风控关键
  • 最新价：当前最新成交价
  • 目标位/止损：系统给出的理想止盈止损参考位
  • 盈亏比：目标利润÷止损风险，≥2 为优秀

🎯 第三步：正确使用系统

  • 优先高胜率品种：历史验证胜率 ≥ 60% 的品种优先看

  • 概率思维：没有 100% 的信号，做好仓位管理和止损
